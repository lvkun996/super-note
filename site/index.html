滚动切换版本
  1. v0.1.19 2026.09.02

    修复在线更新下载

    补齐客户端自动更新配置，让检测、下载与后续升级保持连贯。

    • 修复下载更新时 app-update.yml 缺失的错误。
    • 安装包包含更新源与缓存目录，发布前强制校验配置。
    • 增加更新器回归测试与真实在线下载验收。
  2. v0.1.18 2026.09.02

    统一导航配色与置顶分组

    导航区域更协调、更紧凑，常用文件可置顶分组并随工作区保存。

    • 顶栏和顶部标签沿用侧栏配色，操作栏缩小为 32px。
    • 左侧新增 Pinned 分组，可取消置顶，重启后保留状态。
    • 纯文本保存为 .txt，侧栏支持 Ctrl+↑/↓，切回标签保留位置。
    • Ctrl+F 搜索当前页，再按一次搜索全部标签，优化搜索与缩放提示。
  3. v0.1.17 2026.08.28

    保存命名与标签菜单优化

    让新建文本保存后的名称更符合当前上下文，同时收紧标签右键菜单。

    • 首次保存使用当前标签标题，空标题回退为“未命名文本”。
    • 新建文本统一保存为 .snote 文件。
    • 顶部与侧栏标签右键菜单更小、更清晰。
  4. v0.1.16 2026.08.27

    更直接的标签、搜索与保存

    常用操作更易发现，文件保存位置更可控，两种布局保持一致体验。

    • 标签右键新增置顶、删除、编辑和资源管理器定位。
    • 设置默认保存位置与布局模式，右上角新增搜索入口。
    • 文本长按竖向生成多光标并同步输入，修复反向拖选。
    • 缩放提示停留 3 秒并可恢复 100%，帮助新增打赏作者。
  5. v0.1.15 2026.08.25

    可调侧栏、全屏与缩放反馈

    让侧栏更贴合不同工作空间，并让全屏和文本缩放状态清晰可控。

    • 拖拽侧栏边界实时调整宽度，隐藏标题文字与颜色标识。
    • 侧栏模式聚焦单栏编辑，不再提供分割视图操作。
    • Ctrl + H 切换全屏，缩放显示倍率，Ctrl + 0 恢复 100%。
  6. v0.1.14 2026.08.20

    标签导航与 Windows 文件集成

    让标签顺序更自由、布局更灵活，并让常用文本文件更自然地融入 Windows。

    • 标签支持鼠标左键拖拽排序，工作区会自动保存新的顺序。
    • 按 Ctrl + B 在顶部标签栏与左侧紧凑标签菜单之间切换。
    • 优化标签导航层级与拖拽性能，扩展默认打开和资源管理器预览支持。
  7. v0.1.13 2026.08.12

    画板思维导图与内容关联

    让主题、文字和图片在同一张画板上自由组织，并让样式配置更快、更稳定。

    • 新增思维导图、主题跨层级拖动和画板 PNG 导出。
    • 主题可关联文字或图片，拖动连线即可调整两端吸附边。
    • 关联线实时跟随元素移动，样式面板支持夜间模式并优化启动速度。
  8. v0.1.12 2026.08.11

    更新与文本操作优化

    修复更新提示、统一内容字体，并增强文本模块的选中、字号和 Markdown 预览体验。

    • 只在发现高于本地版本的更新时显示更新提醒。
    • 中键拖动支持竖向选中文本，Ctrl + 滚轮调整文本模块字号。
    • 内容区域采用 Codex 正文相同的系统无衬线字体，Markdown 默认进入预览模式。
  9. v0.1.11 2026.08.07

    工作区安全与文件操作优化

    让工作区保存、文件变化处理和 Markdown 阅读更加稳定直接。

    • 增加工作区原子保存、备份恢复和损坏工作区自动恢复。
    • 增加外部文件修改与删除检测，支持最近文件和 Ctrl + P 快速打开。
    • 全局搜索支持标签标题、文件名和文件路径。
    • Markdown 文档默认进入预览模式，编辑与预览可以随时切换。
  10. v0.1.10 2026.08.04

    Tab 状态与全屏弹窗优化

    集中优化标签操作、全屏弹窗与 Windows 文件体验。

    • 当前 Tab 的选中标识移动到尾部操作区域。
    • 鼠标移入标识后切换为关闭图标，减少重复视觉元素。
    • 修复作者与版本全屏弹窗右侧残留空白。
    • 新增 .snote 文件的 Windows 资源管理器预览注册。
  11. v0.1.9 2026.07.20

    标签、托盘与弹窗体验

    让高频切换、托盘访问与窄窗口操作更加直接。

    • 分栏快捷键调整为 Ctrl + Shift + 左/右，Ctrl + 左/右用于切换相邻标签页。
    • 未保存文本标签根据内容自动显示预览标题。
    • 系统托盘改为最近标签菜单，支持 More、新建文本和直接打开标签。
    • 优化文档与版本更新弹窗滚动、全屏版本页和窄窗口标签栏溢出。
  12. v0.1.8 2026.07.17

    链接、搜索与编辑体验

    补齐编辑器中的链接操作、定位与右键菜单细节。

    • 修复文本模块底部部分区域无法点击，以及搜索结果无法滚动到匹配位置。
    • 文本模块与画板支持 Ctrl + 单击 HTTP/HTTPS 链接，并在外部浏览器中打开。
    • 右键菜单新增剪切、粘贴、复制，并限制 JSON 工具仅处理选中文本。
    • 帮助菜单新增官网入口，调整顶部菜单顺序，并按功能拆分核心代码。
  13. v0.1.7 2026.07.09

    透明图标与作者全屏页

    统一应用视觉，并让全屏内容拥有完整的展示空间。

    • 更换透明背景的新 logo，并同步安装图标与系统托盘图标。
    • 作者弹窗改为全屏展示。
    • 优化标签栏 Tab 边框，减少与工作区的视觉重叠。
    • 暂时移除文本对比插件入口，待体验完善后重新启用。

    • 自动识别 Windows 7 / 8 与 Windows 10 / 11 通道并下载对应安装包。
    • 新增 Ctrl + Alt + 空格全局打开或隐藏。

  15. v0.1.4 2026.06.30

    • 支持全局搜索与结果定位。
