# 编辑与保存性能

- 文本分栏通过稳定事件转发和组件缓存隔离；未变化的分栏不因其他文档输入而重新渲染，事件始终调用最新处理函数。
- Markdown 解析合并 120ms 内的连续输入，等待期间保留同一文档的上一份预览，避免反复切换加载提示。
- 选区和锚点共享文字节点索引。长选区先确定可见范围，再测量矩形；高亮节点在拖选、滚动时复用。
- 文本撤销记录保存替换区间与选区、滚动、多光标信息。普通编辑仍逐次撤销，输入法组合继续作为一个事务。每份文档最多 80 条记录、约 8 MiB 文本预算；单次超大粘贴至少保留一个可撤销事务。

## 工作区存储

桌面端只传输变化的标签，保存请求按顺序执行；未成功的保存不更新前端确认状态。

`workspace.json` 保存布局、设置及标签数据引用，标签快照保存在 `workspace.json.tabs/`。每次写入先完成不可变标签数据，再原子替换索引。`workspace.json.bak` 与 `workspace.json.tabs-backup/` 保存上一份有效工作区，并使用独立文件保留正文。

读取时校验标签摘要，损坏或丢失的数据会使该候选失效，由现有恢复流程选择备份。兼容读取旧版包含全部正文的工作区；首次成功保存时迁移，旧文件作为备份保留。定期清理只涉及程序生成的摘要文件，保留当前和备份引用。

手动备份、搬迁工作区时，应一起复制上述四个文件/目录。新索引不是可供旧版应用直接读取的完整工作区，勿只复制索引或直接用旧版应用打开迁移后的数据。浏览器及不提供增量保存能力的测试环境仍使用原有完整工作区格式。

## 进一步优化（2026-10-22）

- 普通输入使用原生文本绘制，停用不需要的镜像排版；选区、链接高亮、搜索、锚点、多光标以及指针命中测试需要时恢复镜像与滚动位置。
- Markdown 解析通过按需加载的共享 Worker 执行，每个分栏只保留最新待处理版本，空闲 30 秒后释放 Worker；不支持 Worker 时保留主线程回退。
- 预览按顶层 Markdown 块比较，只替换变化的块；保留未变化段落、链接、图片及其 DOM。大批量初始内容一次解析，避免逐段调用 HTML 解析器。
- 正文编辑不再重建未变化的导航项、不再重复发送托盘标签列表；导航事件转发到最新回调。
- 慢保存仅保留一个正在写入和一个最新待写快照，退出保存等待最终快照；失败不阻塞后续保存。
- 隐藏窗口暂停磁盘状态轮询，恢复可见或聚焦时立即检查；避免检查任务重叠。
- 欢迎页手写字体异步加载，不再通过全局 CSS 导入阻塞正文样式。
- 画板文本内容缓存、图片延迟加载和异步解码；思维导图子节点计数一次建立索引，避免逐节点扫描全部节点。

### 本机压力基准

`scripts/benchmark-app.cjs` 使用隔离 Electron 配置与模拟 IPC：100 个标签，纯文本约 31.9 万字符 / 8,000 行，Markdown 约 15.6 万字符 / 4,000 段，连续插入 24 次。关闭硬件加速并使用离屏窗口，以暴露软件排版、绘制开销；数据不代表正常 GPU 环境的输入延迟。

| 指标 | 本轮优化前 | 本轮优化后 |
| --- | ---: | ---: |
| 纯文本输入至下一帧 P95 | 965.39 ms | 818.11 ms |
| Markdown 输入至下一帧 P95 | 1088.12 ms | 574.99 ms |
| 纯文本排版总耗时 | 1703.30 ms | 96.72 ms |
| Markdown 排版总耗时 | 6305.74 ms | 165.13 ms |
| Markdown 界面线程脚本总耗时 | 2234.78 ms | 386.45 ms |
| 标签切换 P95 | 285.92 ms | 175.51 ms |
| 输入期间重复托盘同步 | 24 次 | 0 次 |

排版与脚本指标是该场景的累计 Chromium Performance 数据；界面线程脚本时间不包含 Worker CPU 时间。保存仅验证传输和排队行为，不用模拟 IPC 计时冒充真实磁盘吞吐。长文原生 textarea 在软件渲染下仍有明显开销，本轮没有替换编辑引擎，也没有宣称达到绝对性能上限。

本轮原始记录：`.cache/app-performance-before.json`、`.cache/app-performance-after.json`、`.cache/app-performance-after-markdown.json`；最后一份为增量预览完成后的 Markdown 结果。基准需要已有构建，按明确性能任务手动运行，不加入常规发布流程。
