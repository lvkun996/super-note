# Super Note v0.1.41

- 全局快速打开/关闭快捷键支持自定义：在设置中点击输入框录入组合键，保存后立即生效并持久保存；组合键被占用或保存失败时保留原设置，支持恢复默认。
- 文本与 Markdown 编辑时输入 $ 搜索其他笔记，使用方向键和回车选择，或鼠标点击候选项，插入后显示关联卡片，点击即可跳转。
- 笔记关联使用稳定 ID，重命名后仍保持关联；关联插入支持撤销和重做，笔记关闭或移除后显示不可用状态。
- 正文中的本地盘符路径与网络共享路径支持 Ctrl+鼠标左键使用系统默认应用打开；含空格的路径请加引号。普通点击和右键不触发打开。
- 补充快捷键冲突、笔记关联、路径识别和文本及 Markdown 编辑交互的定向检查。

适用系统：Windows 10 / 11。
