# Super Note v0.1.40

- 长文本普通编辑优先使用原生文本绘制；选区仅测量可见范围，并复用文本索引与覆盖节点，减少重复布局。
- Markdown 使用后台 Worker 解析，连续输入只保留最新待处理任务；预览按内容块增量更新，保留未变化内容，空闲时释放 Worker。
- 标签栏、分栏与托盘减少无效更新；欢迎页字体异步加载，窗口隐藏时暂停文件检查，恢复可见后继续检查。
- 工作区仅写入变化的标签内容，并合并等待中的保存请求；支持读取旧格式，保留独立备份，退出时等待最新保存完成。
- 撤销历史采用有容量限制的差量记录，保留逐次编辑与输入法事务，以及光标、选区方向、多光标和滚动位置。
- 优化画板文本与图片加载、锚点位置更新及思维导图子节点统计。

工作区备份提示：新格式的 workspace.json 为索引。手动备份或迁移时，请同时保留 workspace.json、workspace.json.tabs/、workspace.json.bak 和 workspace.json.tabs-backup/；迁移后的数据请使用新版本打开。

适用系统：Windows 10 / 11。
