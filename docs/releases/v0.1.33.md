# Super Note v0.1.33

- 修复已有文件中异常换行导致光标与显示文本不在同一行的问题，统一打开、恢复、普通输入和粘贴的换行处理，同时保持锚点与搜索定位准确；保留空行，不自动覆盖原文件。
- 窗口聚焦时顶部栏与左侧栏背景更透明，文字、按钮和正文保持清晰；失焦恢复原有背景。Windows 11 22H2 及以上使用原生半透明材质，兼容减少透明度与高对比度偏好。
- 欢迎页在“你想写些什么？”、“灵感涌现”和“记录此时”之间随机选择，补充对应英文文案。
- 统一一键发布入口，自动执行测试、安装包验证、更新清单校验、GitHub Release 发布和 Pages 上线确认，支持草稿续传及只读线上复查。
